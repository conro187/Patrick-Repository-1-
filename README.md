Markdown makes it really easy to add formatting to a document just by typing in plain text. 

When writing in Markdown,
always
start a new paragraph with a blank line. 
This is important because
not all Markdown implementations are exactly the same 
But the "blank line" rule applies everywhere. 

Second level heading 
---------------------

The basic formatting Markdown is 
*emphasis* 
and
**strong emphasis**.
We normally think of this as
_italic_
and __bold__
text. 

I can use bold formatting to explain acronyms. For example, 
the next unit is about HTML,
which stand for 
**H**yper **T**ext **M**arkup **L**anguage.
